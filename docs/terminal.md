# Terminal (`.tmux.conf`)

- Prefix: `C-Space` (default `C-b` unbound); `prefix r` reloads the config
- Splits: `\` side-by-side (`split-window -h`), `-` stacked (`-v`); `hjkl` move between panes
- `renumber-windows on`; extended keys (`csi-u`) enabled
- The full **Flexoki Dark** palette is embedded in the file — no external theme
- Status bar: mode indicator (red while the prefix is held) + session name on the left; pane path + date/time on the right, as colored badges with nerd-font glyphs
